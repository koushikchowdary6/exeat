# Code of conduct

This project follows the [Contributor Covenant](https://www.contributor-covenant.org/) version 2.1.

## Our pledge

We pledge to make participation in this project a harassment-free experience for everyone, regardless of age, body size, disability, ethnicity, gender identity and expression, level of experience, education, socio-economic status, nationality, personal appearance, race, religion, or sexual identity and orientation.

## Our standards

Examples of behavior that contributes to a positive environment:

- Using welcoming and inclusive language
- Being respectful of differing viewpoints and experiences
- Accepting constructive criticism
- Focusing on what is best for the project
- Showing empathy towards other community members

Examples of unacceptable behavior:

- Harassment, trolling, or insulting comments
- Public or private personal attacks
- Publishing others' private information without permission
- Other conduct which could reasonably be considered inappropriate in a professional setting

## Enforcement

Report unacceptable behavior by opening an issue or a private security report on the project repository once it is published. The maintainer will review and respond. This project has no paid support desk.
